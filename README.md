## 📌 About

**Fair-Gig** is a hackathon project aimed at solving the fairness problem in the gig economy. Traditional freelancing platforms often suffer from algorithmic bias, opaque pricing, and unfair ranking of workers. Fair-Gig is built to be different — transparent, equitable, and community-first.

---

## ✨ Features

- 🔍 **Smart Matching** — Connects clients with the right freelancers based on skills and availability
- ⚖️ **Fair Ranking** — No pay-to-win algorithms; workers ranked by merit and reviews
- 💬 **Real-Time Communication** — Built-in messaging between clients and gig workers
- 📊 **Transparent Pricing** — Clear fee structure with no hidden charges
- 🔐 **Secure Authentication** — JWT-based login and role management
- 📁 **Profile & Portfolio System** — Freelancers can showcase their work

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- Node.js (for frontend)
- pip

### Installation

```bash
# Clone the repository
git clone https://github.com/muneeb-sajid/Fair-gig.git
cd Fair-gig/FairGig-Hackathon/Back-end

# Install Python dependencies
pip install -r requirements.txt

# Run the backend server
python app.py
```
